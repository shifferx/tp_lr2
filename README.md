# Учебный веб-сервер на чистом Python с демонстрацией уязвимостей (ЛР №2)

> **ДИСКЛЕЙМЕР:** Данный проект создан исключительно в **учебных и исследовательских целях** в рамках выполнения лабораторной работы по курсу «Технологии программирования». Приложение намеренно содержит уязвимости безопасности из списка OWASP Top 10 и не предназначено для использования в реальных системах.

## Описание проекта
Веб-приложение представляет собой прототип интернет-магазина сумочек, написанный на чистом Python (стандартная библиотека `socket` + `sqlite3`) без использования сторонних веб-фреймворков.

### Реализованные уязвимости (OWASP Top 10):
1. **Небезопасная передача параметров и манипуляция с ценой (A01: Broken Access Control / Parameter Tampering):**
   - При переходе на страницу оформления заказа цена товара передается в открытом виде в параметрах URL (`/pay?product_id=1&price=3000`).
   - Сервер доверяет присланному значению цены и не сверяет его с базой данных, что позволяет злоумышленнику изменить стоимость товара в адресной строке браузера перед оплатой.
2. **SQL-инъекция и обход бизнес-логики склада (A03: Injection):**
   - Идентификатор товара и количество обрабатываются без строгой валидации типов и подставляются в SQL-запрос с помощью конкатенации строк (`f-string`).
   - Это позволяет внедрить SQL-конструкцию (например, `1 OR 1=1`) и оформить заказ на количество товаров, превышающее реальный остаток на складе.

## Состав файлов
- `server.py` — исходный код уязвимого HTTP-сервера.
- `exploit.py` — автоматизированный скрипт на основе библиотеки `requests`, демонстрирующий эксплуатацию обеих уязвимостей.
- `patch.diff` — файл патча в формате `unified diff`, устраняющий уязвимости (внедрены параметризованные SQL-запросы и серверная валидация данных).
